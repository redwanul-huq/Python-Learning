## 📌 About

This repository is a collection of Python scripts, mini-projects, and notes I'm building while learning Python as an ECE student. It's not meant to be perfect — it's meant to show progress. Each folder represents a topic or a project, moving from fundamentals toward more applied work (data handling, small AI/ML experiments, and eventually embedded-related scripting).
